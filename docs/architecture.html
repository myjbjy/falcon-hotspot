🦅 Falcon Hotspot 猎鹰热点追踪系统 · 系统架构

多源热点采集 → 跨源聚类评分 → AI 日报 → GitHub Pages 可视化 · 全自动无人值守 · Shell Engineering 第五形态

成本结构（¥/月）

  • • 采集 / 评分 / 报告 / 站点：¥0（纯 Python + 免费公开接口）
  • • 高频刷新 8 次/天 + 监控 watchdog：no_agent 模式，零 LLM 成本
  • • LLM 解读：每日 1 次 deepseek flash ≈ ¥0.05/天 ≈ ¥1.5/月
  • • 托管：GitHub Pages 免费 · 合计 ≈ ¥1.5/月

可靠性设计

  • • 单源失败隔离：10 源中 ≥5 源成功即继续，失败源记录在案
  • • 双新鲜度监控：日报归档 30h + 站点数据 4.5h，超时即告警
  • • watchdog 连续 2 天异常才报警，单次抖动静默不骚扰
  • • 百度 TLS 抖动 / GitHub / CSDN 断连：源内自动重试

可扩展性

  • • 新增源 = 继承 BaseSource + 注册，3 步完成
  • • 反爬源预留 CDP 兜底（B站 / 抖音 / 微信 待接入）
  • • 评分权重可调（sources 类 weight 字段）
  • • 站点模板独立（web.py PAGE），可整体换肤
